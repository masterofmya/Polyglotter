# Polyglotter

A social 3D world for practicing languages. Walk around as a blocky character, step through portals into language rooms (English, French, Italian, Spanish, German, Portuguese), and chat with people. Click "Translate" on any chat message to see it in your language.

## Run it
1. Install Node.js (nodejs.org)
2. In this folder run `npm install`, then `npm start`
3. Open http://localhost:3000 (open two tabs to see multiplayer)

## Controls
WASD move · Mouse look · Space jump · Shift run · Enter chat · E sit · Hold click to draw on whiteboards · C clear board · Esc free your mouse
