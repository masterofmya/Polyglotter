# Lingo Lobby

A social 3D world for practicing languages. Walk around as a blocky character, step through portals into language rooms (French, English, Italian, German, Spanish), and chat with people. Click "Translate" on any chat message to see it in your language.

## Run it
1. Install Node.js (nodejs.org)
2. In this folder run `npm install`, then `npm start`
3. Open http://localhost:3000 (open two tabs to see multiplayer)

## Controls
WASD move · Mouse look · Space jump · Shift run · Enter chat · Esc free your mouse
